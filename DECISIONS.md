# Design Decisions

## 1. Product and Design Strategy

I chose to redesign **Talent-IQ**, an existing real-time technical interview platform, instead of inventing a new product. This allowed me to use the product's actual workflow and interface rather than relying on fabricated testimonials, customer logos, or usage statistics.

The redesign focuses on communicating the core workflow within the first few seconds: an interviewer creates a session, a candidate joins the session, and both collaborate during the technical interview. I replaced unsupported marketing metrics with clear product capabilities and prioritized showing the actual product interface as the primary visual.

The homepage uses a focused value proposition, a single primary call to action, and a real product showcase to make the product understandable without requiring the user to explore the application first.

## 2. Trade-off Under the Time Limit

The main trade-off was prioritizing **product presentation over adding more marketing content**.

Instead of building a large landing page with pricing, testimonials, customer logos, and multiple decorative sections, I focused the available time on the hero section, real Talent-IQ UI, responsive layouts, visual hierarchy, and a restrained interaction.

With a full week, I would spend additional time refining accessibility, testing the homepage across more devices and browsers, improving animation performance, and adding a more interactive product demonstration based on the actual interview workflow.

## 3. AI Usage

I used AI tools as a development and design-review assistant during the project. AI was also used to **generate and structure coding interview problems** that could be used in Talent-IQ's question dataset.

I reviewed the generated problems manually before using them, checking that the problem statements, constraints, examples, expected outputs, and difficulty were appropriate for a technical interview. I made changes where the generated content was ambiguous, incorrect, or not suitable for the platform.

For the homepage redesign, I also used AI to review the existing UI, improve the value proposition and information hierarchy, identify unsupported marketing claims, and iterate on implementation ideas.

I personally verified the generated suggestions against the actual Talent-IQ application and assignment requirements. In particular, I removed fabricated metrics such as user counts, session counts, and uptime claims and chose to showcase the real Talent-IQ product instead of relying on generic marketing illustrations.
